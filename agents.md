# Pautas de desarrollo

- Mantener el proyecto en HTML, CSS y JavaScript nativos.
- Usar español en el contenido y preservar la identidad JP reparaciones.
- Conservar el teléfono y la integración de WhatsApp indicados en memory.md.
- Mantener estructura semántica, foco visible, contraste y adaptación móvil.
- No incorporar afirmaciones comerciales, reseñas ni datos del negocio sin confirmar.
- Verificar sintaxis de JavaScript, enlaces internos y enlaces de contacto después de cambios.
- Archivos principales: index.html, styles.css y script.js.
